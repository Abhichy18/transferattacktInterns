## Reference paper
- **Title:** *Transferable Adversarial Attack for Both Vision Transformers and Convolutional Networks via Momentum Integrated Gradients*
- **Authors:** Hualin Ma, Yifei Gao, Yingchao Ma, Shiqi Wang
- **Venue:** ICCV 2023
- **Paper:** https://openaccess.thecvf.com/content/ICCV2023/papers/Ma_Transferable_Adversarial_Attack_for_Both_Vision_Transformers_and_Convolutional_Networks_ICCV_2023_paper.pdf

## Important note
This repository stores the student-integrated CNN face-verification adaptation. The implementation is a practical adaptation of the paper’s momentum integrated gradients idea inside the shared face-verification pipeline and should not be treated as an official reproduction of the original authors’ full implementation details.
